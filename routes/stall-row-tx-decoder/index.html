TX Decoder

StallRow · POST https://stall-row-production.up.railway.app/v1/tx-decoder

$0.002 USDC per call · 2000 atomic units (Base accept)

Decode one Base transaction into plain English: sender, receiver, ETH value, status, the known method behind the selector, every ERC-20 transfer it made, and a one-sentence summary. Use this when an agent needs to explain or verify what a transaction actually did before acting on it.
