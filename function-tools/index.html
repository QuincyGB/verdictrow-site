Function-calling schema pack — drop-in LLM tools

OpenAI- and Anthropic-format function-calling tool definitions for every Verdict Row route priced $0.05 or less — 24 tools, generated from the canonical fleet route registry (registry generated 2026-11-04T05:17:22Z) by the fleet-checker's function_tools.py, so prices and request schemas cannot drift from the routes' live discovery terms.

Download the pack: function-tools.json — one JSON file carrying both formats (openai: a list of {"type": "function", "function": {...}} tools; anthropic: a list of {name, description, input_schema} tools), plus the route index and payment terms.

Each tool is a paid POST endpoint on the x402 exact scheme (USDC on Base, payTo 0x097f9685D1e0752bF8B02d61E5Ce9be7eA0FBA7F): an unpaid call returns HTTP 402 with the payment challenge — paste the tool definitions into your LLM's tool list, fund a wallet, and the model can call the fleet directly. No API key, no signup. Every tool description states its price, what it returns, and when to call it, in the route's own discovery wording.
