Agent-Card Verifier

StallRow · POST https://stall-row-production.up.railway.app/v1/agent-card-verify

$0.005 USDC per call · 5000 atomic units (Base accept)

Agent-Card Verifier — an ERC-8004 agent id (resolved on Base via the registry) or an agent.json URL in; the card is fetched and checked against live reality: declared endpoints probed unpaid (402 is correct for a paid service), challenge payTos compared with the card's declared wallets, declared prices with live challenge amounts. Undeclared fields report not_checked, never a guess; an unreachable card errors honestly, unsettled. Use this when an agent's card claims more than its endpoints do.
