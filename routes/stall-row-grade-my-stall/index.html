Grade My Stall

StallRow · POST https://stall-row-production.up.railway.app/v1/grade-my-stall

$0.005 USDC per call · 5000 atomic units (Base accept)

Grade My Stall — a seller-side report card for one x402 resource: a live unpaid probe (does it answer 402 with a parseable challenge?), the description measured against the 500-character limit, CDP listing presence in the newest catalog snapshot, Settled's record, the origin's x402scan ownership declaration, and payTo consistency across sources. Checks that cannot be performed report unverified, never a guess. Use this when you run a stall and want to know how buyers' tools see it.
