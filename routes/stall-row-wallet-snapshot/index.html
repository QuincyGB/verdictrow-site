Wallet Snapshot

StallRow · POST https://stall-row-production.up.railway.app/v1/wallet-snapshot

$0.005 USDC per call · 5000 atomic units (Base accept)

Snapshot one Base wallet in a single call: ETH balance, top token holdings, first and last activity, and outgoing transaction count. Use this when an agent needs a wallet's shape before deciding to pay, trust, or transact with it. Explorer fields that cannot be supplied come back marked unknown, never invented.
