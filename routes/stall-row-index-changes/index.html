Verdict Index

StallRow · POST https://stall-row-production.up.railway.app/v1/index/changes

$0.1 USDC per call · 100000 atomic units (Base accept)

Verdict Index — the CDP Bazaar catalog changelog: the diff between our two newest full-catalog snapshots (price, asset, network, payTo, description, service name), with added and removed resources counted. Snapshots refresh about every 6 hours; until two exist this returns 502 and charges nothing. Filter by resource, payTo, service name, or network — every chain covered, Solana included; the summary breaks counts down by network. Use this when a router needs what changed since its last sync.
