Repo Vitals

StallRow · POST https://stall-row-production.up.railway.app/v1/repo-vitals

$0.005 USDC per call · 5000 atomic units (Base accept)

Vital signs for one GitHub repository in a single call: stars, forks, open issues, license, last push, archived flag, and a 0-100 health score with a verdict line. Use this when an agent is choosing a dependency, a repo to contribute to, or a project to trust, and needs the quick read before the deep one.
