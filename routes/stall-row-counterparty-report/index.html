Counterparty Report

StallRow · POST https://stall-row-production.up.railway.app/v1/counterparty-report

$1 USDC per call · 1000000 atomic units (Base accept)

Counterparty Report — one bundled report on one seller: the payTo's wallet snapshot, an OFAC SDN exact-match screen, and its Verdict Index listing history, plus a Token Verdict when you name a token, a LockSmith audit when you name a service URL, and a ListSmith grade when you name a listing URL. Legs that are not requested or cannot run are marked, never padded. Use this when an agent is about to rely on a seller it has never dealt with.
