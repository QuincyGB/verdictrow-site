Ledger Dataset (full)

StallRow · POST https://stall-row-production.up.railway.app/v1/ledger-dataset/full

$1 USDC per call · 1000000 atomic units (Base accept)

Ledger Dataset (full) — every route in the fleet's x402 observation ledger: observed/listed terms, latest status, check/change/recovery counts, derived defect class, catalogue listing + usage counters, and its patrol block (open defect by class, first/last seen; or recovery + receipt id), plus the per-origin rollup and provenance. Sources: Recheck history, held CDP + patrol snapshots; observation data only. Use this when you need route-level state for monitoring, grading, or dataset work.
