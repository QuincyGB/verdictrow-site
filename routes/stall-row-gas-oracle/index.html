Gas Oracle

StallRow · POST https://stall-row-production.up.railway.app/v1/gas-oracle

$0.001 USDC per call · 1000 atomic units (Base accept)

Current Base gas in one call: the live gas price, the current base fee, the base-fee range across the last 20 blocks, whether fees are rising, falling, or flat, and a cheap-window hint drawn from that data. Use this when an agent wants to time a transaction instead of paying whatever the moment charges.
