PayTo Pin Verify

StallRow · POST https://stall-row-production.up.railway.app/v1/payto-pin/verify

$0.01 USDC per call · 10000 atomic units (Base accept)

PayTo Pin Verify — check one pinned x402 route against its first-seen payTo set: a fresh unpaid probe compares the live payTo set with the pin's hash-committed baseline, answering MATCH, MOVED with before/after sets, or ROUTE_GONE as a delivered report. A swap fires one signed PAYTO_MOVED webhook per distinct new set. Pins are created free at POST /v1/payto-pin. Use this when a payTo swap must be caught before you pay the route again.
