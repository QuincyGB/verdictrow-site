Orchestrate

StallRow · POST https://stall-row-production.up.railway.app/v1/orchestrate

$0.75 USDC per call · 750000 atomic units (Base accept)

One combined fleet report for $0.75: Token Verdict's verdict on a token, RouteVerdict's delivery check and LockSmith's security audit summary on a service URL, and ListSmith's grade on a listing URL — four fleet services in one call. A failed leg is marked in the report, not hidden; only a total failure returns 502 and charges nothing. Use this when an agent is about to trust a token and a stall in the same workflow and wants one receipt instead of four payments.
